# Эксперименты с облаками точек

Все шесть эффектов находятся в разделе «Эффекты → Эксперименты». Их можно сочетать друг с другом. Для первого знакомства включайте по одному на демо-модели или фотографии.

| Эффект | Что попробовать |
|---|---|
| Автофагия | Повращайте камеру, затем остановитесь и дайте контурам вырасти. Кнопка очистки сбрасывает накопленную деформацию и прошлый кадр. |
| Реактивная кожа | Щёлкните по поверхности, чтобы добавить очаг. «Подача» и «Распад вещества» меняют режим реакции, «Мутация» вытягивает плотные участки в объём. |
| Невозможная скульптура | Добавьте две другие формы в список морфинга. Они будут видны примерно через 120° и 240° от первого ракурса. При возвращении к первому ракурсу видна исходная форма. |
| Раны во времени | Дайте модели подвигаться и проведите по ней левой кнопкой. Рана вытягивает несколько слоёв прошлых положений. Для вращения используйте Alt и левую кнопку или среднюю кнопку. |
| Фазовая интерференция | Добавьте вторую форму в список морфинга и включите музыку. Точки переключаются между двумя положениями по интерференционному полю. При нулевой скорости поле по-прежнему реагирует на ракурс и звук. |
| Рекурсивная анатомия | Приближайте камеру. До трёх уровней копий используют точки исходного облака, перераспределяя их между уровнями. |

Автофагия считывает уменьшенную копию последнего отрисованного кадра. Реактивная кожа обменивается концентрациями Gray–Scott между соседними занятыми ячейками пространства. Эти эффекты и раны хранят состояние на сетке 32 × 32 × 32, общей для точек, которые изначально попали в одну ячейку.

История ран хранит до 18 снимков положений из морфинга, анимации модели, видео и накопленного роста. Позиции снимков рассчитываются до остальных шейдерных деформаций. Рекурсивные копии видео используют текущий кадр источника. Для боковых видов и второй формы из списка морфинга подгружается до 65 536 образцов на форму.

# Эксперименты с облаками точек

В списке «Эксперименты» остаются **Поглощение** (бывший «Голод»), **Узор** (бывшая «Химия») и **Ракурс**. Другие инструменты находятся там, где ими удобнее пользоваться.

| Инструмент | Где искать | Что попробовать |
|---|---|---|
| Поглощение | Эффекты → Эксперименты | Включите складки, увеличьте сцепление и поверните камеру. Сжатые участки притягивают соседние и постепенно прореживаются. «Разъедание» управляет тем, насколько заметны пустоты. Цвет и яркость свечения настраиваются отдельно. |
| Узор | Эффекты → Эксперименты | Колонии узора растут по поверхности: «Пятна», «Лабиринт» или «Жилки». Щёлкните по форме или включите посев по биту. Настройки: скорость и размер колонии, размер узора, покрытие, извилистость, мягкость края, рельеф, размер точек, свечение кромки. Цвет: из палитры сайта со сдвигом или «Как модель». |
| Ракурс | Эффекты → Эксперименты | С каждой из трёх сторон (0°, 120°, 240°) форма выглядит по-своему: «Как есть», «Скрутка», «Волна», «Шар», «Силуэт», «Пыль», «Кубики», «Ваза» или «Фото». Крутите сцену или включите вращение формы. У каждой стороны своя сила, зоны можно повернуть, а переход настроить: плавность, разброс точек, дуга, свечение. Фото нужно только для вида «Фото», остальные работают с самой формой. |
| Шрамы | Эффекты → Управление → Кисть → Инструмент | Включите кисть, выберите «Шрамы» и ведите по движущейся форме. Радиус, глубина раны и память слоёв определяют, что поднимется из прошлых положений. |
| Фаза | Форма → Морфинг → Вид перехода | Выберите две формы и переход «Фаза». Узор делит облако между исходной и новой формой. Частота узора меняет плотность полос, глубина границы задаёт всплеск при переключении. |
| Фрактал | Вид → Лаборатория | Включите Фрактал и меняйте число копий, уровень вложенности и масштаб. При приближении становится видно больше копий. |

Поглощение читает предыдущий кадр и учитывает сжатие соседних участков на сетке 32 × 32 × 32. Узор использует ту же сетку только для времени роста: колония считает расстояние вдоль поверхности (кратчайший путь по соседним ячейкам с неровным фронтом), а сам узор шейдер рисует на каждой точке по её нормали, поэтому рельеф получается гладким, а не блочным. Ракурс сортирует образцы облака и фотографии в координатах плоскости вида, чтобы соседние точки переходили в близкие области изображения.

Кисть «Шрамы» хранит до 18 снимков положения облака до прочих шейдерных деформаций. Фрактал в лаборатории перераспределяет существующий бюджет точек между копиями.

## Внутренности

Эффект «Внутренности» (Эффекты → Эксперименты) заполняет объём формы светящимися нитями из точек. Три рисунка:

- **Рост.** Ветви прорастают из корней и заполняют объём: рост идёт к случайным точкам внутри, как у деревьев и сосудов. Настройки: число корней, дальность ветвей, толщина стволов.
- **Нейросеть.** Узлы расставлены по объёму, соседние соединены изогнутыми связями, сигнал расходится из одного узла. Настройки: число узлов, связей у узла, изгиб.
- **Скелет.** Находит ось формы (путь по центру до самых дальних концов), рисует по ней рёбра-кольца и закрученные жгуты. Настройки: рёбра, число жгутов, закрутка, охват, ветвистость.

Общие настройки: плотность, яркость, размер точек, огоньки на узлах, импульсы, цвет (по росту, по высоте или один тон, плюс сдвиг по палитре), скорость роста, повтор («Заново» или «Остаётся») и оболочка (видна, призрак, скрыта). Эффект «Экран» окрашивает нити кадром видео.
